# 단순 위치 정보 확인 서비스 (Web & Flutter) - 지도 버전

컴퓨터나 핸드폰의 위치를 지도로 확인하고, 원하는 지점을 클릭하여 도로명 주소와 우편번호를 추출하는 서비스입니다.

## 🚀 사전 준비 사항 (Prerequisites)

이 코드를 실행하려면 **Google Maps Platform API 키**가 필요하며, 다음 API들을 활성화해야 합니다.

1.  [Google Cloud Console](https://console.cloud.google.com/) 접속
2.  **API 및 서비스 > 라이브러리**에서 다음 항목들을 활성화(Enable):
    -   **Geocoding API** (주소 변환용)
    -   **Maps JavaScript API** (Web 지도 표시용)
    -   **Maps SDK for Android** (안드로이드 앱용)
    -   **Maps SDK for iOS** (iOS 앱용)
3.  코드 내의 `YOUR_GOOGLE_MAPS_API_KEY` 부분을 생성한 API 키로 교체합니다.

---

## 🌐 Web 버전 실행 및 사용법

1.  `index.html` 파일을 브라우저로 엽니다.
2.  **지도 확인**: 하단에 구글 지도가 나타납니다.
3.  **위치 선택**: 지도의 특정 지점을 클릭하면 마커가 이동합니다.
4.  **주소 확인**: 상단의 **"현재 위치 확인할까요?"** 버튼을 누르면 선택된 지점의 도로명 주소와 우편번호가 나타납니다.
    -   지도를 클릭하지 않고 버튼을 누르면, 현재 GPS 위치를 자동으로 가져와 지도에 표시하고 주소를 확인합니다.

---

## 📱 App 버전 실행 및 사용법 (Flutter)

### 1. 설정 및 설치
```bash
flutter pub get
```

### 2. 플랫폼별 추가 설정
-   **Android**: `AndroidManifest.xml`에 API 키 등록 및 위치 권한 추가.
-   **iOS**: `AppDelegate.swift`에 API 키 등록 및 `Info.plist`에 위치 권한 설명 추가.

### 3. 사용법
-   앱 실행 시 하단에 지도가 표시됩니다.
-   지도를 탭(Tap)하여 위치를 시각적으로 지정할 수 있습니다.
-   상단 버튼을 눌러 해당 위치의 상세 주소를 확인합니다.

---

## 🛠 주요 업데이트 사항
-   **레이아웃 변경**: UI 컨트롤러를 상단으로 배치하여 편의성 증대.
-   **지도 통합**: 구글 맵을 하단에 전체적으로 배치.
-   **상호작용**: 사용자가 직접 지도를 클릭하여 위치를 지정하고 시각적으로 확인 가능.
